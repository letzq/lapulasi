# Enterprise Workspace API 文档

## 基础信息

- **Base URL**: `http://localhost:8000/api`
- **Content-Type**: `application/json`
- **认证方式**: Bearer Token (JWT)

---

## 通用响应结构

### 成功响应

```json
{
  "success": true,
  "data": { ... }
}
```

### 分页响应

```json
{
  "items": [ ... ],
  "pagination": {
    "page": 1,
    "pageSize": 10,
    "total": 100,
    "totalPages": 10
  }
}
```

### 错误响应

```json
{
  "success": false,
  "error": "Error message"
}
```

## 认证 API

### 1. 用户登录

**POST** `/auth/login`

**请求体**:

```json
{
  "email": "string",
  "password": "string"
}
```

**请求示例**:

```json
{
  "email": "zhangsan@enterprise.com",
  "password": "password"
}
```

**成功响应** (200):

```json
{
  "success": true,
  "data": {
    "user": {
      "id": "user-001",
      "name": "张三",
      "email": "zhangsan@enterprise.com",
      "avatar": "https://api.dicebear.com/7.x/avataaars/svg?seed=zhangsan",
      "role": "admin",
      "createdAt": "2024-01-01T00:00:00.000Z",
      "updatedAt": "2024-06-29T00:00:00.000Z"
    },
    "token": "jwt-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  }
}
```

**错误响应** (401):

```json
{
  "success": false,
  "data": {
    "user": null,
    "token": ""
  },
  "error": "Invalid credentials"
}
```

### 36. 流式对话（SSE）

**POST** `/rag/chat`

**请求头**:

```
Content-Type: application/json
Authorization: Bearer <token>
```

**请求体**:

```json
{
  "session_id": "string",
  "content": "string"
}
```

**请求示例**:

```json
{
  "session_id": "session-001",
  "content": "请总结 Q3 基础设施合规要求"
}
```

**成功响应** (200, SSE 流式响应):

```
Content-Type: text/event-stream

data: {"type":"chunk","content":"根据"}

data: {"type":"chunk","content":"提供"}

data: {"type":"chunk","content":"的"}

data: {"type":"chunk","content":"公司政策"}

data: {"type":"done","message":{"id":"msg-xxx","role":"assistant","content":"根据提供的公司政策..."}}

data: [DONE]
```

**SSE 事件格式**:

| 类型 | 描述 | 数据结构 |
|------|------|----------|
| chunk | 文本片段 | `{ type: "chunk", content: "string" }` |
| done | 完成 | `{ type: "done", message: Message }` |
| error | 错误 | `{ type: "error", error: "string" }` |

**curl 测试**:

```bash
curl -X POST http://localhost:8000/api/rag/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -N \
  -d '{"session_id": "session-001", "content": "Hello"}'
```

**JavaScript 前端调用**:

```javascript
const response = await fetch('/api/rag/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ session_id, content })
})

const reader = response.body.getReader()
const decoder = new TextDecoder()

while (true) {
  const { done, value } = await reader.read()
  if (done) break

  const chunk = decoder.decode(value)
  const lines = chunk.split('\n')

  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const data = line.slice(6)
      if (data === '[DONE]') break

      const parsed = JSON.parse(data)
      if (parsed.type === 'chunk') {
        // 实时显示文本
        console.log(parsed.content)
      } else if (parsed.type === 'done') {
        // 对话完成
        console.log('Message:', parsed.message)
      }
    }
  }
}
```
