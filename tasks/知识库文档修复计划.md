# 知识库文档管理修复计划

## 问题清单

| # | 问题 | 严重度 | 根因 |
|---|------|--------|------|
| 1 | 文档列表文件名乱码 | 🔴 | multer 中文文件名编码问题 |
| 2 | 无法删除文档 | 🟡 | 前端未对接删除接口 |
| 3 | 列表过长无滚动 | 🟡 | 对话框内容区无固定高度 |

## 修复方案

### 问题 1：文件名乱码

**根因**：multer 使用 `Buffer.from(file.originalname, 'latin1').toString('utf8')` 解码，但 Windows 环境下原始编码可能是 GBK。

**修复**：
- 在 multer 的 `storage` 配置中，手动处理文件名编码
- 使用 `iconv-lite` 或直接用 `Buffer.from(originalname, 'latin1').toString('utf8')` 转换
- 如果转换后仍乱码，尝试 GBK 解码

### 问题 2：删除文档

**后端**：已有 `DELETE /api/rag/documents/:id`，会同时删除：
- ChromaDB 向量数据
- 本地文件
- 数据库记录（级联删除 chunks）
- 更新知识库 document_count

**前端**：
- 在文档列表每行添加删除按钮
- 调用 `deleteDocument(id)` 后刷新列表

### 问题 3：列表滚动

**修复**：
- 对话框内容区设置 `max-height: 400px; overflow-y: auto`
- 文档列表用 `el-scrollbar` 包裹
