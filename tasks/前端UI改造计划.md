# 前端 UI 改造计划 — 飞书淡雅风格

## 一、问题诊断

### 🔴 核心问题：深色侧边栏

当前侧边栏背景 `#2b2f36`（深灰黑），与飞书的**白色/浅灰侧边栏**完全相反。这是用户反馈"深色背景、主题看不出来"的根源。

### 🔴 Login 页面风格不匹配

当前 Login 用紫色渐变背景 `#667eea → #764ba2`，与飞书的淡雅蓝白风格格格不入。

### 🟡 main.css 与 variables.scss 冲突

存在两套设计变量系统，`main.css` 定义了 `--sidebar-bg: #1e293b`（深蓝黑），`variables.scss` 定义了 `--sidebar-bg: #2b2f36`（深灰黑），互相覆盖。

### 🟡 CRUD 操作图标不统一

各页面的操作按钮（增删改查）使用 Element Plus 默认图标，没有统一的视觉语言。

### 🟡 页面间距/密度不一致

Home、Analytics 用 `v-loading` 全屏加载，Assets/Knowledge 也是，但 Agents 完全不同。

## 二、飞书设计语言提炼

| 维度 | 飞书特征 | 当前状态 |
|------|----------|----------|
| 侧边栏 | **白色背景**，选中项蓝色竖条 + 浅蓝底 | ❌ 深色背景 |
| 顶栏 | 白色，极细底边框 | ✅ 基本一致 |
| 内容区 | `#f7f8fa` 浅灰 | ✅ 一致 |
| 卡片 | 白色，无阴影或极微阴影 | ✅ 基本一致 |
| 主色 | `#3370ff` 飞书蓝 | ✅ 一致 |
| 图标 | 线性图标，18px，灰色 | ⚠️ 部分用了 filled 图标 |
| 文字 | `#1f2329` 标题 / `#646a73` 正文 / `#8f959e` 次要 | ✅ 基本一致 |
| 按钮 | 主按钮实色，次按钮白底蓝边，文字按钮无边框 | ⚠️ 次按钮样式缺失 |
| 表格 | 无边框，行间细线分隔 | ✅ 一致 |

## 三、改造计划

### 阶段 1：设计系统修正（基础层）

**改动文件：** `variables.scss`, `global.scss`, `element-override.scss`, `main.css`

| 项 | 改前 | 改后 |
|----|------|------|
| 删除 main.css | 两套变量冲突 | 删除，只保留 variables.scss |
| 侧边栏背景 | `#2b2f36`（深色） | `#ffffff`（白色） |
| 侧边栏文字 | `#ffffff` / `#a0a4ad` | `#1f2329` / `#646a73` |
| 侧边栏选中 | 蓝色半透明底 | 左边蓝色竖条(3px) + `#f0f5ff` 浅蓝底 |
| 侧边栏分割线 | `rgba(255,255,255,0.1)` | `#f0f0f0` |
| 按钮次级样式 | 无 | 白底 + 蓝色边框 + 蓝色文字 |

### 阶段 2：Layout 页面重做

**改动文件：** `Layout.vue`

- 侧边栏：白色背景，左侧 logo 区域留白，菜单项选中时左侧显示 3px 蓝色竖条
- 顶栏：保持白色，搜索框改为浅灰底圆角
- 新建对话按钮：改为次级按钮样式（白底蓝边），放在侧边栏底部

### 阶段 3：Login 页面重做

**改动文件：** `Login.vue`

- 去掉紫色渐变背景，改为白色/极浅蓝灰背景
- 登录卡片居中，去掉左侧装饰区（移动端不友好）
- 简洁风格：logo + 标题 + 表单 + 登录按钮

### 阶段 4：CRUD 操作图标统一

**改动文件：** `Assets.vue`, `Knowledge.vue`, `Agents.vue`

统一操作图标规范：

| 操作 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 新增 | `Plus` | 主色蓝 | 用于创建按钮 |
| 编辑 | `Edit` | 主色蓝 | link 按钮 |
| 删除 | `Delete` | 红色 `#f53f3f` | link 按钮，需二次确认 |
| 查看 | `View` | 主色蓝 | link 按钮 |
| 上传 | `Upload` | 主色蓝 | 用于上传按钮 |
| 搜索 | `Search` | 灰色 | 输入框前缀 |
| 筛选 | `Filter` | 灰色 | 筛选栏 |

### 阶段 5：各页面微调

| 页面 | 改动 |
|------|------|
| Home | 统计卡片 hover 效果，快捷操作卡片加图标背景色 |
| Assets | 卡片列表改为更紧凑的布局，操作按钮统一 |
| Knowledge | 知识库卡片加入文档数统计的视觉优化 |
| Agents | 会话列表侧边栏适配白色主题 |
| Analytics | 图表卡片保持现有风格 |
| Settings | 适配白色侧边栏 |

## 四、需要确认

1. **侧边栏风格**：改为白色背景 + 蓝色选中竖条（飞书风格），是否确认？深色侧边栏完全去掉。

2. **Login 页面**：去掉紫色渐变，改为白底简洁风格，是否接受？还是保留某种渐变但换成蓝色系？

3. **新建对话按钮**：从侧边栏底部的实色主按钮，改为白底蓝边次级按钮，还是保持实色？

4. **阶段优先级**：先做哪个？建议按 1→2→3→4→5 顺序。
